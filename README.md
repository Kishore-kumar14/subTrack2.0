# SubTrack 💳📊
> Centralized Subscription & Expense Intelligence Platform

SubTrack is a modern, responsive web application designed to help users track subscriptions, monitor recurring monthly & annual expenses, visualize spending analytics, and receive timely alerts before renewals and free-trial expirations.

---

## ✨ Features

- 📈 **Real-time Spending Analytics**: Interactive charts and breakdowns by category, billing cycle, and payment method.
- 🔔 **Renewal & Trial Expiration Alerts**: Track upcoming renewals with active status indicators to avoid surprise charges.
- 🗂 **Comprehensive Subscription Management**: Add, edit, filter, search, and categorize all your recurring subscriptions.
- 🎨 **Modern Dark UI**: Glassmorphic styling, smooth micro-interactions, and responsive layout powered by modern CSS.
- ⚡ **Lightning Fast**: Built on React 18 and Vite for blazing-fast development and optimized production bundles.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts & Visualizations**: [Recharts](https://recharts.org/)
- **Styling**: Modern Vanilla CSS with CSS Variables & Responsive Design

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or newer recommended) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kishore-kumar14/subTrack.git
   cd subTrack
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Building for Production & Deployment

To generate an optimized production bundle:

```bash
npm run build
```

The output files will be created in the `dist/` directory, ready to be deployed to any static hosting provider (e.g., [Vercel](https://vercel.com), [Netlify](https://netlify.com), [Cloudflare Pages](https://pages.cloudflare.com), or GitHub Pages).

To preview the production build locally:

```bash
npm run preview
```
